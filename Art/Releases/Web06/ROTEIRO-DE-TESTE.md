# Web Teste 06

1. Continuar save com antiga preferência de catálogo ligada: roupas disponíveis devem respeitar reputação/entregas. Novos saves começam com o catálogo inicial. Configurações não mostra botão de catálogo de teste.
2. Jogar → save → casa. Em tela cheia, P abre pausa sem sair da tela cheia. P/Retomar devolve câmera; um clique basta no botão Retomar.
3. Repetir P em diálogo e provador. Digitar P no nome do personagem não pausa.
4. Esc continua pausando; onde o navegador/iframe reserva Esc, também pode sair da tela cheia. Não confundir isso com falha de pausa. Use P para preservar a tela cheia.
5. Configurações permite sair voluntariamente da tela cheia. A ajuda de controles destaca P na web. Windows continua usando Esc e desbloqueios normais.
